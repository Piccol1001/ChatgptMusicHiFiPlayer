# Windows download

[Download Snowbound for Windows x86_64 (35 MB)](https://github.com/Piccol1001/ChatgptMusicHiFiPlayer/raw/refs/heads/main/penguin-catapult/downloads/Snowbound-Windows-x86_64.zip)

Extract the ZIP, then double-click `Snowbound.exe`. No Godot installation or Internet connection is needed to play. Space or left mouse launches/dives; Esc pauses.

The executable is unsigned. The Windows export passed, but Windows execution still needs laptop testing. See [validation](../VALIDATION.md) and [full instructions](../README.md). `SHA256SUMS.txt` contains the archive checksum.

The game source is in the parent `penguin-catapult/` directory. The unrelated Android music-player application is unchanged.
