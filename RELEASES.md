# Known APK releases

Metadata below was inspected inside the APKs with Android build tools; filenames alone are not evidence. The package remains `com.piccol.hifi`. Historical dates identify the first verifiable repository publication, not an inferred APK compilation time. No uploaded APK binaries were supplied in this conversation; uploaded files were text specifications. Android SDK/emulator system APKs are unrelated and excluded. Build-directory APKs are transient candidates, not automatically released versions.

The two historical installable APKs use the same development certificate (SHA-256):
`322612b8f4ffae7f3e47ac07f9f4357e1944ecc8c4c71a1ee0cbfd013a2d2428`.
Unsigned release variants cannot be installed until signed. No owner production signing certificate has been supplied. Signing with a different certificate breaks ordinary in-place updates; keep the original private key secure outside Git. The workflow refuses missing or changed debug keys and does not generate one.

Versions 0.2.0–0.4.0 are not known released APKs. Development phases are not evidence of released versions. Old 0.1.0 APKs have also been restored byte-for-byte from Git history under their original filenames; they were not relabeled. Current 0.5.0 files are retained unchanged. New artifacts are append-only. `releases/history.json` is the machine-readable ledger; its existing entries are immutable.
